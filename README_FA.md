# Qeshm Life — C++ / raylib

این پروژه یک نمونه‌ی سه‌بعدی جهان‌باز کوچک با C++ و کتابخانه‌ی raylib است.

## امکانات فعلی
- دوربین سوم‌شخص و چرخش دوربین با دکمه راست ماوس
- حرکت شخصیت با WASD و کلیدهای جهت
- دویدن با Shift
- خودرو و رانندگی با نزدیک‌شدن و فشردن E
- تغییر شب و روز با N
- نقشه کوچک با M
- محیط ساحلی الهام‌گرفته از قشم، خیابان‌ها، ساختمان‌ها، بازار، نخل‌ها، مسجد، اسکله و قایق‌ها

## ساخت روی کامپیوتر
نیازمندی‌ها: CMake، یک کامپایلر C++17 و Git.

از پوشه پروژه اجرا کن:

```bash
cmake -S . -B build
cmake --build build --config Release
```

فایل اجرایی در پوشه `build` ساخته می‌شود.

## نکته مهم درباره اندروید
این پوشه **سورس کد C++** است، نه فایل APK آماده. برای تبدیل آن به APK باید Android NDK، ابزار ساخت raylib برای Android و امضای برنامه تنظیم شود. ویرایشگر Acode به‌تنهایی معمولاً این پروژه سه‌بعدی را کامپایل و به APK تبدیل نمی‌کند.

## کنترل‌ها
- WASD / کلیدهای جهت: حرکت
- Shift: روشن/خاموش‌کردن دویدن
- E: سوار یا پیاده‌شدن از خودرو
- N: تغییر شب و روز
- M: نمایش/مخفی‌کردن نقشه
- نگه‌داشتن دکمه راست ماوس و کشیدن: چرخاندن دوربین
